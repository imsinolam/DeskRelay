# DeskRelay 0.2.3

Release date: 2026-08-21

## What's new

- ClawBot's task list is now ordered strictly by the most recent update time. It no longer reshuffles the first page to reserve a place for every terminal; running, approval, and input states remain visible beside each task.
- DeepSeek Harness task listing now rediscovers the currently running DSH Desktop, so current tasks and pending interactions remain available after the desktop host restarts or changes its local endpoint.
- The public repository removes five unused legacy demo images and documents the DeepSeek Harness URL override in the configuration example.

## Fixes

- Fixed older running tasks or tasks from another terminal being moved ahead of newer work, which made task numbers appear out of chronological order.
- Fixed task listing continuing to read from an old DeepSeek connection after DSH Desktop restarted, potentially hiding the newest tasks or pending approvals.

## Upgrade notes

- No re-login is required, and the mobile web password, device pairing, and existing task links keep working.
- Update both the computer-side DeskRelay and the public Relay, then safely restart both services.

## Known limitations

- The task list only aggregates terminals that are currently connected or visibly running on the computer; older tasks may require pagination or a “任务：关键词” search.
- WeChat completion and approval notices are still subject to the WeChat context validity period; after a long silence, send a fresh message to ClawBot first to restore the context.
