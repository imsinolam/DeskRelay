# DeskRelay 0.2.0

发布日期：2026-08-17

## 这次更新

- 在正式版确定之前，DeskRelay 统一使用 `0.x.x` 版本号；此前的 `2.x` 记录保留为历史预览版本，不代表已经进入正式稳定阶段。
- DeskRelay 常驻后台启动时只保持微信、移动网页和公网连接在线，不再主动打开、激活或切换 ChatGPT；用户从手机端明确选择终端或发送消息后，才连接对应的真实任务。
- Codex 桌面连接短暂中断时，会优先恢复自己的辅助连接，不再因为辅助进程退出而重启 ChatGPT 或整个 DeskRelay。

## 修复的问题

- 修复后台连接失败时可能反复拉起 ChatGPT、打断当前窗口和任务的问题。
- 修复旧的连接重试可能误关已经恢复的新连接，导致稍后再次断开的情况。
- 修复 Windows 自动检查中因路径写法、命令启动方式、通信方式和文件权限差异造成的连续失败。
- 修复后台环境找不到用户安装的 Codex 命令，以及桌面应用更新后仍使用旧命令版本的问题。

## 升级说明

- 升级后无需重新登录，也无需修改已有移动网页密码、设备配对或任务链接。
- 电脑端常驻服务需要使用安静启动方式；本次部署会自动更新启动配置，并短暂重启 DeskRelay。
- 本次更新需要同时更新电脑端 DeskRelay 和公网 Relay。

## 已知限制

- 公网网页仍要求电脑端 DeskRelay 在线；单独运行 ChatGPT 或 DeepSeek Harness 不代表公网设备已经在线。
- 微信通知仍受微信上下文有效期影响，长时间没有新的微信消息时，可能需要先向 ClawBot 发送一条新消息恢复上下文。
- 历史 `2.x` 版本说明继续保留用于追溯，但后续预正式版本只使用 `0.x.x`。
