# DeskRelay 0.2.2

发布日期：2026-08-18

## 这次更新

- 在 ClawBot 里直接发送“任务”，即使还没有选择任何终端，也能看到当前已连接或电脑上正在运行的各终端任务汇总；第一页会保证每个有任务的终端至少出现一条，不会被任务多的单个终端挤满。
- 查看任务列表是纯查看操作：不会为了列出任务而自动启动任何 Agent、恢复旧任务，也不会让电脑桌面跳到某个 ChatGPT 任务。
- DeepSeek Harness 现在可以自动识别电脑上正在运行的 DSH Desktop，无需手工填写地址即可从 ClawBot 使用 `/deepseek` 或 `/dsh` 接入。

## 修复的问题

- 修复服务重启或微信长时间无消息后恢复时，积压的多条完成通知逐条刷屏的问题；现在会合并成一条汇总，说明共几条、涉及哪些任务。
- 进一步收紧后台任务枚举行为，确保仅为读取任务列表而建立的连接不会改动桌面端正在查看的任务，也不会触发桌面应用启动。

## 升级说明

- 升级后无需重新登录，也无需修改移动网页密码、设备配对或现有任务链接。
- 本次更新需要同时更新电脑端 DeskRelay 和公网 Relay，并安全重启两个服务。

## 已知限制

- 公网网页仍要求电脑端 DeskRelay 在线；单独运行 ChatGPT、WorkBuddy 或 DeepSeek Harness 不代表公网设备已经在线。
- 微信完成通知和审批通知仍受微信上下文有效期影响，长时间没有新消息时，可能需要先向 ClawBot 发送一条新消息恢复上下文。
