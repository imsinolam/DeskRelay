# WeRelay 0.3.0

发布日期：2026-08-22

## 这次更新

- 项目已正式更名为 WeRelay。公开仓库、安装包、命令、配置项和运行目录现在使用统一的新名称，电脑端、移动网页和 ClawBot 仍然接力同一条真实任务。
- 从 DeskRelay 升级时，WeRelay 会自动复制已有的微信登录、设备配对、任务状态和附件记录，旧目录会保留，不会被删除或覆盖。
- 公网连接暂时不稳定时，任务短链接仍可直接打开；移动网页也会明确区分“服务器不可达”和“电脑尚未连接”，并持续显示等待时间或重试进度。

## 修复的问题

- 修复短链接尚未来得及完成登记时，用户已经收到的链接可能永久打不开的问题。
- 修复公网连接中断后，移动网页可能把服务器故障误显示为电脑离线、且恢复过程缺少明确反馈的问题。
- 统一清理了移动网页和公网 Relay 中残留的旧品牌名称，避免同一版本里混用两个项目名。

## 升级说明

- 需要卸载旧的 `deskrelay` 安装包，并重新安装 `werelay`；原有 `deskrelay-*` 命令不再提供，请改用对应的 `werelay-*` 命令。
- 自定义配置中的 `DESKRELAY_*` 需要改为 `WERELAY_*`，后台服务和公网 Relay 也需要同步升级并安全重启。
- 首次启动 WeRelay 时会自动复制旧数据；请先保留 `~/.deskrelay`，确认新版运行正常后再自行决定是否归档。

## 已知限制

- 本版本不会自动修改用户自行维护的域名、证书、系统服务名称或第三方脚本；这些外部配置需要在部署时同步更新。
- 微信完成通知和审批通知仍受微信上下文有效期影响，长时间没有新消息时，可能需要先向 ClawBot 发送一条新消息恢复上下文。
