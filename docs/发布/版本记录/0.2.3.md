# DeskRelay 0.2.3

发布日期：2026-08-21

## 这次更新

- ClawBot 的“任务”列表现在统一按最近更新时间排列，不再为了让每个终端都出现在第一页而打乱顺序；正在运行、等待审批和等待输入仍会直接显示在对应任务旁边。
- DeepSeek Harness 的任务列表会重新识别当前正在运行的 DSH Desktop，即使桌面端重新启动或更换了本地连接，也能继续读取当前任务和待处理状态。
- 公开仓库移除了五张已经没有使用入口的旧演示图，并在配置示例中补充 DeepSeek Harness 地址覆盖方式，目录更精简、配置入口更完整。

## 修复的问题

- 修复任务较多时，较旧的运行任务或其他终端任务被提前插入列表，导致序号看起来没有严格按时间排列的问题。
- 修复 DeepSeek Desktop 重新启动后，DeskRelay 仍从旧连接读取任务列表，可能看不到最新任务或待审批状态的问题。

## 升级说明

- 升级后无需重新登录，也无需修改移动网页密码、设备配对或现有任务链接。
- 本次更新需要同时更新电脑端 DeskRelay 和公网 Relay，并安全重启两个服务。

## 已知限制

- “任务”列表只汇总当前已连接或电脑上明确正在运行的终端；较旧任务可能需要翻页或使用“任务：关键词”查找。
- 微信完成通知和审批通知仍受微信上下文有效期影响，长时间没有新消息时，可能需要先向 ClawBot 发送一条新消息恢复上下文。
