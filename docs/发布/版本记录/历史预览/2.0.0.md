# DeskRelay 2.0.0

发布日期：2026-08-07

## 主要变化

- npm 包统一为 `deskrelay`；
- 主入口统一为 `deskrelay`，其余公开命令统一使用 `deskrelay-*`；
- 活动数据目录统一为 `~/.deskrelay`；
- DeskRelay 自有环境变量统一使用 `DESKRELAY_*`；
- README 重构为产品关系、最短安装和网络模式说明；
- 明确微信 ClawBot、局域网网页、公网网页和电脑真实 Agent 的职责边界；
- 公网访问统一推荐应用层 Relay，Mac 主动连接服务器，不直接暴露本机端口；
- 发布流程只维护一个 npm 包，不再生成兼容镜像。
- 增加干净历史公开快照、已审核公开插画、依赖审计和仓库安全元数据。

## 破坏性变更

旧 npm 包和旧命令别名不再发布，旧 `CLI_BRIDGE_*` 环境变量不再作为活动配置读取。服务脚本、LaunchAgent、systemd 和个人 shell 配置需要同步改用新名称。

## 数据迁移

首次启动 2.0 时，DeskRelay 会从 1.x 数据目录一次性复制缺失的登录状态、同步游标、工作区任务映射、附件和更新缓存到 `~/.deskrelay`。迁移不会覆盖新目录已有文件，也不会删除或继续写入旧目录。

完整命令和变量映射见 [运行配置](../../../使用指南/运行配置.md#从-1x-迁移到-20)。
