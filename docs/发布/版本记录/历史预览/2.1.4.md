# DeskRelay 2.1.4

发布日期：2026-08-17

## 这次更新

- 补齐 DeskRelay 多端任务协作与发布职责说明，方便后续维护时明确产品验收、微信入口、移动网页、Agent 接入和正式发布分别由谁负责。
- 将上一版已经上线的移动终端状态与安全安装引导整理到正式公开版本基线中。

## 修复的问题

- 修复后续协作中容易把功能开发、发布部署和验收工作混在同一个任务里的问题。
- 统一说明手机端继续电脑原任务的边界，减少误以为会创建另一条隐藏会话的情况。

## 升级说明

- 升级后无需重新登录，也无需修改已有移动网页密码、任务链接或终端配置。
- 本次更新需要同时更新电脑上的 DeskRelay 和公网 Relay，并短暂重启服务。

## 已知限制

- 本版本没有新增已知限制。
- 公网网页仍要求电脑端 DeskRelay 在线；微信通知仍受微信上下文有效期影响，长时间没有新的微信消息时可能需要先发送一条新消息恢复上下文。
