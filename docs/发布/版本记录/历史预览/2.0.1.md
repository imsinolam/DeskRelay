# DeskRelay 2.0.1

发布日期：2026-08-08

## 安全与可靠性

- POSIX 上统一保护 `~/.deskrelay`：运行目录使用 `0700`，凭据、状态、令牌、日志和附件使用 `0600`，并在启动时修复旧安装权限；
- Codex 完成通知改为持久化的待发送、发送中、已送达状态，微信上下文令牌过期、部分发送失败或 daemon 重启后都能继续补发，完整送达后才去重和清理；
- Relay CLI 默认只监听 loopback，非本机监听必须显式启用危险开关并显示警告；
- 为长期运行缓存增加容量和 TTL 限制，减少敏感路径长期驻留和内存无界增长。

## 兼容性与构建

- `LegacyAdapterRuntime` 正确转发 `createSessionInProject` 并保留方法绑定；
- `prepack` 在构建前强制运行源码类型检查，避免跳过类型错误的包进入发布流程；
- 保留并整合任务级审批、网页审批结果持久化和移动端交互修复。

本版本没有执行 npm 发布；GitHub 源码与本机验收安装使用同一份 `npm pack` 产物。
