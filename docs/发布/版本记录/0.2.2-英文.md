# DeskRelay 0.2.2

Release date: 2026-08-18

## What's new

- Sending “任务” in ClawBot now works even before any terminal is selected: it aggregates tasks from terminals that are currently connected or visibly running on the computer, and the first page guarantees at least one task from each terminal so a busy terminal cannot crowd out the others.
- Listing tasks is strictly read-only: it never starts an agent, never resumes an old task, and never moves the desktop UI to a ChatGPT task just to build the list.
- DeepSeek Harness can now auto-discover a running DSH Desktop on the computer, so `/deepseek` or `/dsh` in ClawBot works without manually configuring an address.

## Fixes

- Restarting the service or recovering after a long WeChat silence no longer floods the chat with one completion notice per message; backlogged completion notices are merged into a single summary stating how many there are and which tasks they belong to.
- Background task enumeration is further tightened so connections created only to read the task list cannot change which task the desktop is showing or launch the desktop application.

## Upgrade notes

- No re-login is required, and the mobile web password, device pairing, and existing task links keep working.
- Update both the computer-side DeskRelay and the public Relay, then safely restart both services.

## Known limitations

- The public web still requires the computer-side DeskRelay to be online; running ChatGPT, WorkBuddy, or DeepSeek Harness alone does not make the public device online.
- WeChat completion and approval notices are still subject to the WeChat context validity period; after a long silence, send a fresh message to ClawBot first to restore the context.
