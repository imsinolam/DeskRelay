## 1. 数据原则

- **完全虚构：** 任务、路径、时间、命令、域名和消息都不是用户真实数据。
- **真实结构：** 任务状态、ClawBot 任务列表格式、进入任务、审批和完成通知贴合当前 DeskRelay 行为。
- **单一故事：** 所有截图围绕同一条任务展开，证明“手机读取原任务列表并继续原任务”。
- **可回填：** JSON 中有稳定的演示 ID，确认后可以逐项映射到专门创建的 Codex 演示任务。

## 4. 主任务故事

任务标题：**修复图片上传后重复显示**

电脑端开始排查图片重复显示。用户离开电脑后，从 ClawBot 读取电脑上的任务列表，进入这条原任务，处理测试审批，再补充一条验收要求。该补充要求随后原样出现在电脑端 Codex 任务中，最后 ClawBot 收到同一任务的完成结果。
