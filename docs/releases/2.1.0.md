# DeskRelay 2.1.0

Release date: 2026-08-15

## What changed

- Added DeepSeek Harness integration. Send `/deepseek` or `/dsh` in ClawBot to enter it. DeskRelay reuses the active Harness web owner so WeChat and mobile web can continue the same session, answer approvals, and stop work without exposing internal reasoning.
- ClawBot now uses short task links for both LAN and public access instead of exposing long task identifiers. Each link still opens the correct agent and task.
- On first entry, agent switches, task switches, and task-board opening, the mobile web app shows the last saved tasks and messages first, then refreshes them automatically in the background without an empty loading wait or manual reload. Signing out clears this local content, and images, approval details, and login credentials are not stored there.
- The web app now uses a lightweight freshness check before downloading full messages. Unchanged content briefly shows “Up to date” without reloading the conversation; changed content shows a small “Syncing updates” indicator and refreshes automatically. A running timer changing by itself no longer causes a false content update.
- Codex task models can now be viewed and changed from the mobile web app. Model selection is temporarily locked while a task is running and becomes available again after completion or stop.
- New tasks accept text and selected images immediately without waiting for desktop creation. Unsent drafts are preserved per agent and task, including after a creation failure.
- The mobile web app now distinguishes connection, loading, running, approval, and failure states more clearly, and restores recent messages, drafts, and progress faster after task switches.
- WeChat approval handling is more reliable: pending notifications can resume after reconnection, multiple approvals can be handled in sequence, and task-scoped approval choices are preserved.

## Fixed

- Fixed completed Codex replies appearing in the web app without being delivered to WeChat ClawBot. Final replies are now recovered even when newer Codex records omit the older phase marker.
- Fixed internal thinking tags leaking into web or WeChat replies. User-facing channels now receive only the visible answer text.
- Fixed new tasks jumping back to an older task, creating duplicate empty tasks, or losing unsent text and images before the new task appeared in the task list.
- Fixed unclear or slow startup, restore, approval, and exit handling for selected Claude, TClaude, Grok, and WorkBuddy flows, while continuing to refuse silent fallback to a different task.
- Fixed transient network conditions causing duplicate requests or messages, or making an active task appear completed too early.

## Upgrade notes

- Deployment briefly restarts the local DeskRelay service and the public Relay. Existing login and configuration remain valid.
- Open mobile pages use version detection to load the new build. If WeChat still shows an older page, close it and reopen the newest task link.
- This release is deployed from the reviewed package artifact and is not published to the public npm registry.

## Known limitations

- Mobile model switching currently supports Codex and DeepSeek Harness and is available only while the selected task is not running.
- WeChat proactive replies remain subject to the platform context window. DeskRelay retries still-valid notifications after the next inbound WeChat message but cannot bypass the platform limit itself.
