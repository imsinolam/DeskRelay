# DeskRelay 2.1.2

发布日期：2026-08-17

## 这次更新

- 手机网页新增“设置”页面，可以查看每种终端是否支持继续任务、发送图片、排队、审批和停止，并看到缺少哪些本机条件。
- 手机网页可以临时开启“严格审批”。开启后，所有需要授权的操作都必须由你确认，不再自动放行低风险操作或当前任务的免审请求。
- 在 ClawBot 连续发送多张图片时，DeskRelay 会先暂存图片，等你补充完整说明后再作为一条任务发送，避免第一张图片过早触发任务。较短的说明会先询问是否已经写完，也可以保留图片后重新填写或直接取消。
- 超长 Codex 任务的进度和最近回复改为只读取必要的尾部内容，持续查看时更省电脑资源。

## 修复的问题

- 修复电脑端仍在等待审批、但手机任务列表、页头或正文卡片提前显示为已处理的问题。现在审批状态以电脑端的实际结果为准，确认失败或超时时仍会保留可操作入口。
- 修复开启任务免审后，电脑端没有真正接受审批时，手机和 ClawBot 可能看不到这项待处理请求的问题。

## 升级说明

- 本次升级需要同时更新电脑上的 DeskRelay 和公网 Relay，并短暂重启两个服务。
- 升级后无需重新登录，也无需修改已有移动网页密码或任务链接。
- “严格审批”在当前运行期间立即生效；服务重启后会恢复为电脑环境中的默认设置。
- 本版本使用审核后的安装包和 GitHub 快照部署，暂不发布 npm 公共仓库。

## 已知限制

- 公网网页的发送消息、审批、停止和新建任务仍需要电脑在线；电脑离线时只能查看浏览器缓存或 Relay 最近一次验证过的只读内容。
- 微信主动回复仍受微信上下文有效期影响；DeskRelay 可以在连接恢复后补发仍有效的通知，但不能绕过微信平台本身的时效限制。
