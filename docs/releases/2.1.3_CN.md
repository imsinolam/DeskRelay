# DeskRelay 2.1.3

发布日期：2026-08-17

## 这次更新

- 手机网页的“设置”页现在会直接显示每个终端的可用状态：已经安装、尚未启动、需要安装或正在安装，并说明它负责什么、是否能继续电脑上的同一条任务。
- 对少数已经明确支持的终端，设置页新增“一键安装”。安装只会执行 DeskRelay 内置登记过的固定安装项，不会执行用户输入的任意命令；安装完成后会自动重新检查状态。
- DeepSeek Harness、OpenCode 等终端会分别显示命令、后台服务和可选配置的状态，缺少其中一项时不再笼统显示为“在线”。
- 设置页改为从右侧打开的抽屉，并把终端信息和任务入口收拢到更简洁的页面结构，手机上更容易查看和切换。

## 修复的问题

- 修复某个终端只缺少可选组件时，整个终端被误判为不可用的问题。
- 修复已经安装但后台服务尚未启动时，页面无法区分“软件缺失”和“服务未启动”的问题。
- 修复手机设置页显示的能力、依赖和电脑端真实检测结果不一致的问题。

## 升级说明

- 本次升级需要同时更新电脑上的 DeskRelay 和公网 Relay，并短暂重启两个服务。
- 升级后无需重新登录，也无需修改已有移动网页密码或任务链接。
- 一键安装需要电脑能够访问对应软件源；安装完成后，必要时仍需按终端提示登录或启动桌面应用。
- 本版本使用审核后的安装包和 GitHub 快照部署，暂不发布 npm 公共仓库。

## 已知限制

- 一键安装目前只覆盖 DeskRelay 已登记且明确安全的安装项；桌面应用、账号登录和本机服务启动仍需按提示手动完成。
- 安装过程在电脑上执行，手机页面关闭后不会中断；服务重启后会重新检测结果。
- 公网网页的发送消息、审批、停止和新建任务仍需要电脑在线。
