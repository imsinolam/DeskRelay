# DeskRelay 2.1.4

Date: 2026-08-17

## Changes

- Added public documentation for the project's task ownership and release responsibilities across product acceptance, WeChat, mobile web, agent integration, and deployment.
- Formalized the mobile provider status and safe installation guidance that shipped in the previous runtime baseline.

## Fixes

- Clarified the boundary between feature development, release operations, and acceptance work.
- Clarified that mobile entry points continue the computer's real task instead of creating a hidden replacement session.

## Upgrade notes

- No re-login, mobile password change, task-link change, or provider reconfiguration is required.
- Update both the computer DeskRelay and the public Relay; both services restart briefly during deployment.

## Known limitations

- No new known limitations were introduced.
- The public page still requires the computer DeskRelay to be online. WeChat notifications remain subject to the WeChat context-token lifetime and may require a fresh incoming message after a long idle period.
