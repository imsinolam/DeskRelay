# DeskRelay 2.0.0

Release date: 2026-08-07

## Highlights

- Renamed the npm package to `deskrelay`.
- Standardized public commands on `deskrelay` and `deskrelay-*`.
- Moved active runtime data to `~/.deskrelay`.
- Standardized DeskRelay-owned environment variables on `DESKRELAY_*`.
- Reworked the README around the relationship between desktop Agents, WeChat ClawBot, LAN web, and public web.
- Standardized internet access on the application-layer Relay: the Mac initiates the connection and no local general-purpose port is exposed.
- Removed compatibility mirror publishing and legacy command aliases.
- Added a clean-history public snapshot workflow, reviewed public artwork, dependency auditing, and repository security metadata.

## Breaking changes

Legacy npm packages, command aliases, and `CLI_BRIDGE_*` active configuration are no longer published or read. Update shell profiles, LaunchAgents, systemd units, and service environments to the new names.

## Data migration

On first start, DeskRelay 2.0 copies missing login state, sync cursors, workspace mappings, attachments, and update cache from the 1.x data directory into `~/.deskrelay`. Existing 2.0 files are never overwritten, and the old directory remains untouched but inactive.

See [Configuration](../configuration.md#from-1x-to-20) for the complete migration table.
