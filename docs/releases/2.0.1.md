# DeskRelay 2.0.1

Release date: 2026-08-08

## Security and reliability

- Protects `~/.deskrelay` consistently on POSIX: runtime directories use `0700`, while credentials, state, tokens, logs, and attachments use `0600`; legacy installations are repaired on startup.
- Persists Codex completion delivery as pending, in-flight, and delivered state so stale WeChat context tokens, partial sends, and daemon restarts can resume safely; replies are deduplicated and cleared only after full delivery.
- Restricts the Relay CLI to loopback by default. Non-loopback listening now requires an explicit dangerous override and a prominent warning.
- Bounds long-lived caches with capacity and TTL limits to reduce unbounded memory growth and retention of sensitive paths.

## Compatibility and packaging

- Forwards `createSessionInProject` through `LegacyAdapterRuntime` while preserving method binding.
- Makes `prepack` run source type checking before compilation so packages cannot bypass TypeScript failures.
- Preserves and integrates task-level approval, persisted web approval results, and mobile interaction fixes already present in the working tree.

This release does not publish to npm. The GitHub source and the locally accepted installation are built from the same `npm pack` contents.
