# DeskRelay 2.1.0

发布日期：2026-08-15

## 这次更新

- 新增 DeepSeek Harness 接入。在 ClawBot 中发送 `/deepseek` 或 `/dsh` 即可进入；DeskRelay 会复用已经打开的 Harness 网页任务，微信和手机网页可继续同一个任务、处理审批和停止操作，内部思考不会显示在用户消息中。
- ClawBot 发出的内网和外网任务链接现在都是短链，不再显示很长的任务编号；打开后仍会准确进入对应的终端和任务。
- 首次进入手机网页、切换终端、切换任务或打开任务看板时，会先显示上次保存的任务和消息，再在后台自动读取最新内容并更新页面，不需要等待空白加载，也不需要手动刷新；退出登录会清除这些本地内容，图片、审批详情和登录信息不会写入其中。
- Codex 任务可以直接在手机网页中查看和切换模型；任务正在回复时会先锁定选择，完成或停止后即可切换。
- 新建任务时可以立即输入文字和选择图片，不必等待桌面端创建完成；尚未发送的草稿会按终端和任务保留，创建失败后也可以继续重试。
- 手机网页更清楚地区分正在连接、正在读取、正在处理、等待审批和执行失败，切换任务后会更快恢复最近消息、草稿和进度。
- 微信端的审批处理更可靠：待审批通知可以在连接恢复后补发，也支持按顺序一次处理多项审批，并保留任务范围内的免审选择。

## 修复的问题

- 修复 Codex 已在网页中生成完整回复，但微信 ClawBot 没有推送完成消息的问题；即使新版记录没有旧式阶段标记，也会识别并发送真正的最终回复。
- 修复内部思考标签可能出现在网页或微信回复中的问题；用户端现在只会看到可公开的回答正文。
- 修复新任务尚未出现在任务列表时自动跳回旧任务、重复创建空任务，或丢失未发送文字和图片的问题。
- 修复部分 Claude、TClaude、Grok 和 WorkBuddy 启动、恢复、审批或异常退出时提示不清楚、等待过久或错误恢复到其他任务的问题。
- 修复网络短暂波动时网页重复请求、重复显示消息，或把仍在处理的任务误显示为已完成的问题。

## 升级说明

- 本次部署会短暂重启 DeskRelay 本机服务和公网 Relay；恢复后无需重新登录，也无需修改现有配置。
- 已经打开的手机网页会通过版本检测加载新版；若微信内置浏览器仍停留在旧界面，关闭页面后从最新任务链接重新打开即可。
- 本版本继续通过审核后的安装包部署，没有发布到 npm 公共仓库。

## 已知限制

- 网页模型切换目前支持 Codex 和 DeepSeek Harness，并且只能在该任务没有正在执行的回复时操作。
- 微信主动回复仍受微信上下文有效期影响；DeskRelay 会在收到下一条微信消息后补发仍有效的通知，但无法绕过微信平台本身的时效限制。
