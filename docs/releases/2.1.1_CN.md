# DeskRelay 2.1.1

发布日期：2026-08-15

## 这次更新

- 公网 Relay 会在浏览器打开之前，提前准备最近的任务列表、任务状态和消息尾部。首次进入公网网页或切换最近任务时，可以更快看到上次内容，再由后台自动同步最新变化。
- 微信完成通知中的任务链接进一步缩短，不再把完整任务编号编码在链接里；旧版短链接继续有效，Relay 重启后新短链接也仍可打开原任务。
- 微信任务列表、搜索结果和帮助提示移除了重复的横向分隔线，手机上阅读更紧凑。

## 修复的问题

- 修复 ClawBot 长轮询已经收到响应头、但响应正文停住时可能一直没有反应的问题。现在超过时限会主动结束本次请求并重新连接，不会让进程看似在线却收不到新消息。
- 修复公网 Relay 重启后新生成的短任务链接可能失效的问题；短链接映射会保存在权限受限的服务器状态文件中。

## 升级说明

- 本次升级需要同时更新电脑上的 DeskRelay 和公网 Relay，并短暂重启两个服务。
- 升级后无需重新登录、无需修改移动网页密码，已有 `/t/...` 任务链接继续兼容。
- 标准 systemd 部署会使用 `/var/lib/deskrelay` 保存短链接映射；使用自定义服务配置时，请确保对应状态目录仅服务账号可读写。
- 本版本通过审核后的安装包和 GitHub 快照部署，暂不发布 npm 公共仓库。

## 已知限制

- 公网网页的发送消息、审批、停止和新建任务仍需要电脑在线；电脑离线时只能查看浏览器缓存或 Relay 最近一次验证过的只读内容。
- 微信主动回复仍受微信上下文有效期影响；DeskRelay 可以在连接恢复后补发仍有效的通知，但不能绕过微信平台本身的时效限制。
