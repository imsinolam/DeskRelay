# DeskRelay 0.2.0

Date: 2026-08-17

## Changes

- Until a stable release is explicitly declared, DeskRelay now uses the `0.x.x` version series. Earlier `2.x` records remain as historical preview releases and do not indicate stable-major status.
- The long-running DeskRelay service now keeps WeChat, mobile web, and the public Relay online without opening, activating, or switching the ChatGPT window during startup. It connects to the real desktop task only after an explicit mobile selection or message.
- When the Codex desktop connection is interrupted, DeskRelay recovers its own metadata connection instead of restarting ChatGPT or the whole daemon.

## Fixes

- Fixed repeated ChatGPT launches that could interrupt the current window and task after background connection failures.
- Fixed stale reconnect attempts that could close a newer recovered connection and cause another disconnect later.
- Fixed Windows CI failures caused by platform-specific paths, command launchers, IPC types, and file-permission assumptions.
- Fixed background environments failing to find user-installed Codex commands or continuing to use an older command after the desktop app was updated.

## Upgrade notes

- No re-login, mobile password change, device pairing, or task-link change is required.
- The computer service must use quiet startup mode. This deployment updates the startup configuration and briefly restarts DeskRelay.
- Update both the computer DeskRelay installation and the public Relay.

## Known limitations

- The public page still requires the computer DeskRelay daemon to be online. Running ChatGPT or DeepSeek Harness alone does not make the public device online.
- WeChat notifications remain subject to the WeChat context-token lifetime and may require a fresh incoming message after a long idle period.
- Historical `2.x` notes remain available for traceability, but future preview releases will use only `0.x.x` versions.
